# PROJECT MEMORY & STATE

## 1. Архитектурные решения
- **Среда**: Антигравити ИДЕ + Гемини 3.8 Флеш (режим Build).
- **Управление доступом**: Guardrails в `opencode.json` (ручной апрув на терминальные команды).
- **Контракт агента**: зафиксирован в `AGENTS.md`.
- **Верификатор**: `powershell -File ./verify.ps1`.

### Архитектура продукта PriemTovara (3 контура):
1. **Core App** (корень проекта):
   - Автономный `index.html` (HTML5 + CSS3 + Vanilla JS) без серверных зависимостей.
   - Хранение состояния: `localStorage` (черновики сессий, реферальные лимиты, языковые настройки).
   - Двуязычность: RU/EN со словарем `TRANSLATIONS` (приоритет RU для рынка РФ).
   - Экспорт данных: альбомный Excel A4 (SheetJS) и мобильный адаптивный HTML-отчет (.html).
   - Нативный слой: Capacitor 8 Android (`@capacitor/android`), плагины `@capacitor/filesystem` (через `CACHE`) и `@capacitor/share` (через `files: [uri]`) с санитизацией имен файлов от `#`, `%`, `?`, `*`.
   - CI/CD: облачная сборка в GitHub Actions (`.github/workflows/build.yml`) на Node.js 22 + JDK 21 Temurin.
2. **Mini App** (`miniapp/`):
   - Telegram WebApp на GitHub Pages (`https://sergei123321123.github.io/kladovshik-pay/`).
   - Двухшаговый интерфейс: выбор способа оплаты (СБП/Stars) и генерация/отображение PRO-ключа.
3. **Telegram Bot** (`bot/`):
   - Сервер на Node.js (`@KladActivation_bot`).
   - Прием платежей через Telegram Stars (XTR), автоматическая выдача лицензионных ключей (FNV-1a хэш, соль `KLAD_SALT_2026`).
